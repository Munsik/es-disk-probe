InfoShard allocation awareness not configured · Elasticsearch admin
Evidence
cluster.routing.allocation.awareness.attributes not set · 4 data nodes
Why it matters
If nodes holding a primary and its replica sit on the same physical host (or cloud availability zone), losing that host loses both copies at once. Elasticsearch does not know which host a node runs on.
Action
Add host or availability zone information to each node as an attribute and configure awareness. Also review anti-affinity rules on the virtualization side.
Source: [Elastic official] Shard allocation awareness
